## 0.1.2

Initial public release. This repository was seeded from Linchpin's internal skills library,
so history starts here — earlier development is not part of the public repo.

Ships the skill authoring standard, a validator with CI enforcement, the zero-dependency
installer (Claude Code, GitHub Copilot, Codex, Cursor), and 20 skills covering WordPress
delivery, quality gates, QA, debugging, design, and project management.

Later entries are generated by release-please from conventional commits.
